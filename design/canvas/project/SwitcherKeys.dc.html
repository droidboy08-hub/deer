The switcher, held and latched

Deck, Grid and Strip share one set of keys. What changes is whether Ctrl is still down: held, letting go of Ctrl chooses; latched, Enter does and Esc cancels.

Vitre first: pages never get it · Inside Vitre: only in Vitre’s own fields, menus and panels · New: added by the keyboard map
